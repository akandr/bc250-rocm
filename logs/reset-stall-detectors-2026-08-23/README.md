# Trying to get a backtrace out of the stall, 2026-08-23

Generated by `scripts/netconsole_capture.sh` plus a debugfs reset trigger.

Captured over netconsole with the lockup detectors armed
(`kernel.watchdog_thresh=3`, both panic-on-lockup settings off) so a stalled CPU
would print before the machine went silent.

## Result: no backtrace, but a narrower window

Nothing new was printed. The capture ends at the clocksource watchdog exactly as
before. The reason is timing: the machine dies about 4.3 seconds after the reset
begins, and a soft lockup at `watchdog_thresh=3` needs six. There is no window.

What the capture does add is where the silence starts. The last driver line is
the 40-CU unlock being reapplied to all four shader arrays during resume, and
4.3 seconds later a CPU has stopped answering. Everything before that succeeds:
the reset, PSP, SMU.

It also shows the CPU number is incidental. The earlier captures named CPU 10,
this one names CPU 4. That is whichever CPU the timekeeping watchdog happened to
poll, not a fixed culprit.

## The suspect this raises

The 40-CU unlock is a patch carried by this repository. It writes
`CC_GC_SHADER_ARRAY_CONFIG` and an SPI register on each shader array, and the
resume path reapplies it. Being the last thing logged before the stall does not
make it the cause, but it is testable and it is ours: booting with
`amdgpu.bc250_cc_write_mode=0` disables it, and a reset that then survives would
implicate it directly.

That test was run, and cleared it: booted at `bc250_cc_write_mode=0`, with the
unlock never applied, the board dies at the same point in the same way
([`../reset-ccwrite-2026-08-23/`](../reset-ccwrite-2026-08-23/)). Being last in
the log was all it was.

## One capture

One triggered reset, and the reasoning about timing, that the machine dies about
4.3 seconds after the reset begins while a soft lockup at `watchdog_thresh=3`
needs six, comes from that single run's timestamps. The window it describes is
narrow enough that a second measurement could move it either side of the
threshold.
