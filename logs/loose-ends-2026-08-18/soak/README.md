# Endurance soak on the current stack, 2026-08-18

Generated by `scripts/soak_current_stack.sh`.

The two soaks elsewhere in this repository predate several things now in the
recipe: the corrected patch scripts, the native PyTorch build, and the llama.cpp
patch set as it now stands. They remain valid for what they measured, but
nothing had run for hours on the configuration a reader would build today.

Each round runs a prefill benchmark, a wikitext perplexity gate against the
8.9442 reference, an allocation-churn sweep, and every third round a PyTorch
training loop, so this covers the paths the earlier soaks never touched.

## Result: 42 rounds over 8 hours 4 minutes, nothing moved

    perplexity          one distinct value across all 42 rounds: 8.9442
    prefill (pp2048)    661.27 to 663.61 t/s, a 0.35 percent spread
    allocation churn    42 of 42 clean
    PyTorch training    14 runs, one distinct final loss: 0.00048
    GPU faults          0
    temperature         62 to 71 C

The perplexity figure is the same value the earlier soak returned across its 43
rounds and the same one a single gate returns today, so the number is stable
across builds, boots and months, not merely within one run.

The PyTorch arm is the new part. Fourteen training loops, each 50 Adam steps
over a three-layer network, returned an identical final loss every time. That
matters more than the value itself: it means the training path is not just
working but deterministic across an eight-hour period that also included
hundreds of large allocations and forty-two churn sweeps.

`churn_1.log` and `churn_42.log` are the first and last churn sweeps, kept as
samples; the other forty are omitted for size, and the per-round verdicts are
all in `log`.

## What this does and does not establish

It establishes that the current recipe holds under sustained mixed load on this
board, with no drift in any measured value.

It does not establish anything about other boards, and it is one continuous
session rather than repeated cold boots. The cross-boot evidence is elsewhere:
the kernel ladder, the recipe verified end to end from a pristine tree, and the
perplexity value reproducing across separate boots and kernels.
