# Eight-hour soak, small model, 2026-08-13


Generated by `scripts/soak_fixed_stack.sh`.

`soak.log` has one flaw worth knowing before reading it: the `ppl=` field in
each round line says `0.23`, which is not a perplexity. The harness matched the
log's leading timestamp instead of the value, so that field is meaningless
throughout. It also made the automatic gate inert, so the run was gated by
inspection afterwards rather than during. The bug is fixed in
`scripts/soak_fixed_stack.sh` as shipped; these logs predate the fix.

The real per-round values are in `soak_ppl_per_round.txt`, extracted from the
43 individual perplexity logs: every round returned **11.0521 +/- 0.44756**,
identical to all digits. That is the number the README quotes.

`thermals.tsv` is `epoch<TAB>edge temperature<TAB>shader clock`, sampled every
20 seconds.
