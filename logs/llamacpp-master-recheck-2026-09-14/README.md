Readings:

- **0001 is obsolete on master.** The HIP backend no longer trusts `prop.integrated`, and the
  unpatched build does not show the 168-perplexity corruption the patch was written against.
- **0003 is still required.** Without the gfx1013 entry in the RDNA1 macro, generation is garbled
  and prefill runs at 139 t/s against 793, the same two signatures recorded in
  [`../macro-remeasure-2026-08-18/`](../macro-remeasure-2026-08-18/).
- **0002 is still required, unless the f32 compute type is set.** The gate table above does not
  test it, so it was A/B'd separately with [`../../scripts/kqv_master_ab.sh`](../../scripts/kqv_master_ab.sh)
  in the configuration that exposed it (flash attention off, ctx 2048, two chunks, 1.5B), four
  runs each way on one boot:

  | compute type | with 0002 | without 0002 |
  |---|---|---|
  | `GGML_CUDA_CUBLAS_COMPUTE_TYPE=f32` ([`kqv-master/`](kqv-master/)) | 9.9850 x4 | 9.9850 x4 |
  | unset ([`kqv-master-noenv/`](kqv-master-noenv/)) | 9.9850 x4 | 88.3441, 89.2649, 89.2649, 10.0008 |

  The first row was run with the variable set out of habit and cannot show the defect, since f32
  compute forces the GEMM that 0002 protects to f32 anyway. The second is the real test: without
  the patch three of four runs are corrupt and no two agree with the patched value. Upstream
  #28576 does not cover this path on gfx1013. The front page's recommended variable masks the
  defect as a side effect.
- **The gate values moved with llama.cpp, not with the board.** The old build returns 8.9442 on
  the same boot, bit-identical to the reference. On master both backends move: HIP 8.9490 and
  Vulkan 8.9760 on the 1.5B, HIP 9.1178 and Vulkan 9.1000 on the 8B, agreeing within 0.3 percent
  and inside one standard error (0.18 and 0.59). The 8.9442 reference applies to 7ba604f only.
- Master replaced `--no-mmap` with `--load-mode`; the script uses `-lm none` where available.

The unpatched directory is the script's second run. The first failed every perplexity step on the
removed `--no-mmap` flag and was deleted after the flag was fixed; its text and bench lines matched
the second run.
